# neoMVX
Control software for custom microscopy system consisting of the following hardware components.
- Olympus MVX10 widefield microscopy
- Prior ProScan III stage controller & H112ARNN1 stage
- Hamamatsu ORCA-FLASH4.0 V3 (C13440-20C)
- Sutter Lambda 10-3 filter controller & LB10-NWIQ/LB10-NWE excitation/emission filter wheels
- Chroma Technology Corp. 8900-ET-Sedat Quad filter set
- Advanced Illumination DCS-100E LED controller & BX1111-WHI-IC backlight.

Developed by Ian Jan (Allbritton Lab, Department of Bioengineering, University of Washington) with assistance from Anthropic Claude Sonnet.
